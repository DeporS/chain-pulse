# ChainPulse working agreement

- Work in small, reviewable PRs. Implement only the current stage and wait for the user's local verification before advancing to the next stage.
- Target WSL Ubuntu with Python 3.11+. Explain important data engineering and crypto concepts when they first become relevant.
- Use documented official APIs and public blockchain data. Do not add trading or account credentials to the v0 pipeline.
- Keep tests deterministic and offline. Report manual live-feed checks separately and never claim they passed without actually running them.
- Treat README metrics as measured results only. Note known data gaps and failure modes plainly.
